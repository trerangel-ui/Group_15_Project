# Group 15 – Financial Market Dashboard

Project team: Tre, Kai, Sem, Achille and Elsbeth

The story behind our financial dashboard

The goal of our project was to create a dashboard that makes financial market information easier to understand and explore.

Investing is about more than simply looking at whether a stock price goes up or down. To understand the bigger picture, it is useful to compare different investments and look at how financial markets develop over time.

Our dashboard brings several types of information together. Users can explore stock prices, trading volumes, cryptocurrency information and compare the performance of a selected stock with Bitcoin, government bonds, gold and real estate.

This allows users to identify trends, observe fluctuations and explore how different investments perform in relation to each other.

For example, users can investigate whether different investments move in the same direction, which ones experience larger price changes, and how their performance changes over different time periods.

The main value of our dashboard is that it turns separate financial data into a clearer overview. Instead of just presenting numbers, it gives users the opportunity to explore relationships, ask questions and develop their own understanding of the financial market.

Our dashboard does not tell users what to invest in. It provides information and insights that can help them make more informed decisions.

What can you explore?

- Stock prices: Follow the price development of a selected stock.
- Trading volume: Explore changes in trading activity.
- Investment comparison: Compare a selected stock with Bitcoin, government bonds, gold and real estate.
- Cryptocurrency: Explore cryptocurrency market information.

How to run the project

1. Install Python.
2. Install the Jupyter Notebook extension in Visual Studio Code.
3. Open the project in Visual Studio Code.
4. Select Python as the kernel for the notebooks.
5. Run the cells in `Yfinancecode.ipynb` if you need to install or prepare the required extensions and dependencies.
6. Open and run `GradioTesting.ipynb` to launch the interactive Gradio dashboard.
